# 技術解説 — SONIC COLLAPSE

このドキュメントでは、音響解析から映像生成までの処理を、実装の値とともに説明します。

## 1. 音声の経路

```
AudioBufferSourceNode（音源ファイル / デモ曲）──┬──► AnalyserNode（解析）
                                               └──► GainNode（音量）──► 出力
演奏音（シンセ）──► GainNode ──┬──► AnalyserNode
                               └──► GainNode（音量）──► 出力
```

解析経路を音量スライダーの**前**で分けているため、聴く音量を下げても解析結果は変わりません。
ユーザーが鳴らした音（クリック・キーボード）も同じ解析器に入るため、演奏そのものが世界を動かします。

## 2. 特徴量の抽出（毎フレーム）

| 特徴量 | 計算方法 |
|---|---|
| LOW / MID / HIGH | `getByteFrequencyData` の振幅（0–255）を、20–250Hz / 250–2kHz / 2k–12kHz の範囲で平均し 0–1 に正規化 |
| RMS | `getFloatTimeDomainData` の 2048 サンプルの二乗平均平方根 |
| ビート | 低域の**正のスペクトルフラックス**（前フレームからの増加分）が、直近 50 フレームの平均 + k × 標準偏差を超え、かつ前回のビートから 0.26 秒以上経っていれば検出。k = 1.6 / 感度 |
| BPM | 直近 4 秒のビート間隔の中央値から計算し、80–180 BPM の範囲に収まるよう 2 倍・1/2 倍で補正 |

- **FFT サイズ**：2048（44.1kHz で周波数分解能 約21.5Hz）
- **AnalyserNode の平滑化**：0.55

### 自動ゲイン調整（AGC）

曲ごとに音量が違っても映像の反応が同じくらいになるよう、各特徴量をその時点までの最大値で割って正規化します。最大値は時定数約4秒でゆっくり下げ、静かな曲にも追従します。無音のときにノイズを増幅しないよう、最大値には下限を設けています。

### 平滑化

指数移動平均 `x += (target - x) * (1 - exp(-dt * rate))` を使い、フレームレートが変わっても同じ速さで追従するようにしています。

## 3. フェーズ判定

| 指標 | 意味 |
|---|---|
| level | 短期 RMS（時定数約0.45秒）÷ 曲全体での最大値。曲の中での相対的な音量 |
| jump | 短期 RMS ÷ 長期 RMS（時定数約3.3秒）。音量が急に上がったか（ドロップの検出） |
| density | 直近 4 秒のビート数 |

```
COLLAPSE 中   : level > 0.5 かつ density ≥ 4 なら継続、そうでなければ REBIRTH へ
BUILD/REBIRTH : level > 0.6 かつ density ≥ 3 かつ jump > 1.5（3秒以上経過後）→ COLLAPSE
BUILD         : 14秒以上続き、level > 0.8 かつ density ≥ 6 → COLLAPSE（ドロップの無い曲向け）
REBIRTH       : density ≥ 4（3秒以上経過後）→ BUILD
それ以外      : level < 0.2 または density < 2 → SILENCE、そうでなければ BUILD
```

崩壊にはすぐ入れるよう保持時間を 0.3 秒、それ以外の遷移は 1.6 秒にして、ちらつきを防いでいます。

**ドロップ検出の設計理由**：最初は相対音量だけで判定していましたが、ビルドアップ（盛り上がる途中）も十分大きな音量になるため、ドロップより前に崩壊してしまいました。デモ曲の音量の推移をシミュレーションした結果、ビルド中の jump は 1.3 程度で頭打ちになる一方、ドロップの瞬間は 2.0 前後まで上がることが分かったため、jump > 1.5 をきっかけにしています。

## 4. 映像

### 核（殻）
- 正二十面体（細分化 48）の頂点を、3D シンプレックスノイズで法線方向に変位
  - 低周波ノイズ × 割り当てた特徴量（既定は LOW）：全体のうねり
  - 高周波ノイズ × HIGH：細かい震え
  - `|noise|^0.6` × 崩壊度：とげ状に割れた形
  - 叩いた位置からの距離に応じた減衰正弦波：波紋
- フラグメントシェーダー：フレネル項で縁を光らせ、コサインパレットによる虹色（薄膜干渉風）、`(1 - |noise|)^7` による流れる光の筋
- 加算合成・深度書き込みなしの半透明表現にして、内側の光を透かせている

### 粒子（36,000個、GPU計算）
- 各粒子は方向・半径・シード値だけを持ち、位置はすべて頂点シェーダーで計算
- 崩壊：半径を `1 + explode × (0.4 + seed² × 4.5)` 倍に広げる
- 再生：中心へ流れ込む `1 - fract(seed × 7 + t)` の半径に補間
- カーソル：長押し中は引き寄せ、ホバー中はよける

### ポストエフェクト
UnrealBloom（発光）→ Afterimage（残像、フェーズごとに減衰率を変更）→ RGB Shift（崩壊時のビートでグリッチ）

## 5. デモ曲の合成

外部の音源を使わず、ページ内で 128 BPM・34 小節（約64秒）の曲をサンプル単位で合成しています。

| 小節 | 構成 |
|---|---|
| 0–3 | イントロ（パッドのみ） |
| 4–11 | ビルド（ハット → キック → ベース → ライザー → スネアロール） |
| 12–19 | ドロップ（全パート、パッドにサイドチェイン） |
| 20–23 | ブレイク |
| 24–31 | ドロップ |
| 32–33 | アウトロ |

最後にピークで正規化し、`tanh` でソフトクリップしています。
