HOW IT WORKS

01 音源 → Web Audio API
02 AnalyserNode / FFT 2048点
03 LOW 20–250Hz / MID 250–2k / HIGH 2k–12k
04 RMS（音量）・低域のスペクトル変化でビート候補
05 自動ゲイン調整 → 平滑化
06 音量レベル＋ビート密度でフェーズ判定
07 GLSLシェーダーで球体・粒子・残像・発光へ

SONIC COLLAPSE

音は、世界を創り、壊し、再構築する。

ここに音源ファイルをドロップ（WAV推奨・MP3/M4A/OGGも可、100MBまで）
クリックで叩く／長押しして離すと世界が崩壊／円を描くと再構築
キーボードの Q〜I でメロディ、Z X C V でドラムを鳴らせます。

デモ曲はこのページの中でプログラムから合成した約64秒のオリジナル曲です
（静寂 → 構築 → 崩壊 → 再生 → 崩壊 の展開）。
